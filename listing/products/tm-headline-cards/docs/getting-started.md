# Getting started

Add Tm Headline Cards to a sheet and give it data. These steps use the Qlik Cloud edit mode.

1. Open the sheet and choose **Edit sheet**.
2. Open the Custom objects panel and drag **Tm Headline Cards** onto the sheet.
3. Add the **Category** dimension. Each value gets one card.
4. Add the **Time** dimension, such as a month or a date. It orders the trend line.
5. Add the **Value** measure. The card headline is its latest value.
6. Optionally add the **Comparison** measure, such as a plan or last year's value. The card then shows the change.
7. Choose **Done editing**.

## Limits

The chart shows up to 24 categories. With more, it shows a notice instead of a partial set of cards; filter the sheet to 24 or fewer. Each trend line shows the latest 60 points, and a notice says when older points are hidden.
